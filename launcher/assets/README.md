# Launcher wallpaper

maplestory_wallpaper_01_1600x1200.jpg is the user-selected MapleStory wallpaper from Nexon's website:
https://nxcache.nexon.net/umbraco/5190/maplestory_wallpaper_01_1600x1200.jpg

Downloaded November 14, 2026. The original image and its embedded copyright notice are retained. Artwork belongs to its respective rights holders; this is not original Otono artwork.

Replace maplestory_wallpaper_01_1600x1200.jpg with another local JPG to change the wallpaper. The launcher loads it at startup. If missing or unreadable, it falls back to the classic theme. No download occurs during ordinary launcher startup.
