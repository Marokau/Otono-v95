# v0.2.1 Launcher, configurable rates, and interim job advancement

## Launcher

- Refined the checklist and button layout, improved text readability, and added a Launcher Guide.
- Open Otono.cmd as usual. The setup and start scripts now live in the launcher folder.

## Configurable rates

- Configure normal item drops, boss item drops, dropped mesos, and normal-map monster capacity in config.yaml. The four new rates default to 1.

## Interim job advancement

- Open @wherelevel and choose Interim Job Advancement for the class-family guide. Temporary routes cover standard Explorers, Dual Blade, later Cygnus stages, and later Aran stages. Resistance and Evan use their native quest paths.
- For advancement testing, use @levelup to earn level-up AP and SP. The @level command sets the level directly and clears old EXP when the level changes.
- Search @aio by skill name for available skill-unlock books. Quest-only unlocks still vary by class. First-job Thief and early Dual Blade were tested in-game. Later stages remain provisional.

## Updating

- Stop the server and close the game. Back up config.yaml and server/data/kinoko.db.
- For a Git install, pull the update with git pull --ff-only. Reapply any custom config values if needed. In PowerShell run .\launcher\Initial-Server-Setup.cmd --rebuild, then open Otono.cmd.
- For a ZIP install, extract to a new folder and copy your game files and server/data/kinoko.db to the matching paths. Reapply your custom settings in the new config.yaml and use Initial Setup.
