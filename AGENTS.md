# Otono v95 contributor guidance

- Preserve the Windows launcher and local SQLite setup.
- Build PQ crews through Kinoko's server systems. Keep shared movement and combat behavior separate from quest-specific decisions.
- Preserve normal quest entry requirements, timers, and progression. Document historical sources and flag uncertain behavior or Otono-specific additions.
- Run focused checks for the behavior you change. Distinguish automated tests from in-game client verification, especially for movement and visuals.
- Document significant fixes with the symptom, cause, change, and verification. Keep personal paths, credentials, local saves, logs, and private discussions out of published files.
