# Included Kinoko launcher binaries

The bundled Kinoko.exe launcher comes from iw2d/kinoko_client v95.1.7. Kinoko.dll is built from the local client source with Otono's Magic Claw visual fix, verified in the v95 client. SHA256SUMS.txt records both bundled files.

Initial Setup and Repair Setup install these files beside MapleStory.exe. Install the compatible game files separately.
